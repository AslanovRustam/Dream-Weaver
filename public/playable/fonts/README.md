# Шрифт для плейблов

Inter (вариативный, 100–900) — те же подмножества, что Google Fonts отдаёт для
next/font. Встраивается в файл плейбла base64: сети запрещают внешние запросы,
а системный шрифт на телефонах разный.

- inter-latin, inter-cyrillic — всегда;
- inter-cyrillic-ext (казахский, узбекская и другая кириллица СНГ), inter-latin-ext
  (польский, чешский, румынский, турецкий, азербайджанский…), inter-greek — только
  если в текстах сцены есть их символы (src/lib/scenes/build.ts, EXTRA_FONTS):
  без них такие буквы рисовались системным шрифтом.

Лицензия — SIL Open Font License 1.1 (https://openfontlicense.org): шрифт
можно встраивать и распространять вместе с продуктом.
