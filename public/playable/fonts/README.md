# Шрифт для плейблов

Inter (вариативный, 100–900), подмножества latin и cyrillic — те же файлы, что
next/font берёт с Google Fonts для интерфейса. Встраивается в файл плейбла
base64: сети запрещают внешние запросы, а системный шрифт на телефонах разный.

Лицензия — SIL Open Font License 1.1 (https://openfontlicense.org): шрифт
можно встраивать и распространять вместе с продуктом.
